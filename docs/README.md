# Documentation

Nadi Laravel provides automated monitoring and observability for Laravel applications.
It captures exceptions, failed jobs, slow database queries, HTTP requests, and other events.

## Documentation Structure

### [01. Getting Started](01-getting-started/README.md)

Installation, configuration, and basic usage.

### [02. Architecture](02-architecture/README.md)

System design, event-driven flow, and core components.

### [03. Configuration](03-configuration/README.md)

Environment variables, transport drivers, and sampling strategies.

### [04. Handlers](04-handlers/README.md)

Event handlers for exceptions, queries, jobs, HTTP requests, and more.

### [05. Advanced](05-advanced/README.md)

OpenTelemetry integration and creating custom handlers.
